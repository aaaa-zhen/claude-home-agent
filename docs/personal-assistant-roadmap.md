# 高级个人助理升级路线

## 北极星

高级个人助理不只是“会回答和会调用很多工具”，而是能持续完成四件事：

1. 理解现在最重要的事。
2. 提前准备用户下一步需要的信息和材料。
3. 在授权范围内直接执行，并验证结果。
4. 对承诺持续跟进，直到完成、取消或明确阻塞。

## 当前判断

现有系统的家居、位置、媒体、提醒和本地工具已经很强。最大的短板不是缺少更多脚本，而是任务、提醒、监控和记忆分散在 Markdown、cron、JSON 与多个进程中，没有统一的“承诺账本”。这会导致重复提醒、状态难追踪，以及助手知道很多但不一定知道此刻该做什么。

## P0：先做可靠的承诺系统

建立统一 `commitments` 存储，所有“提醒我、帮我盯着、等回复、下周处理、办好告诉我”都进入同一套状态机：

- `captured`：已记录
- `scheduled`：已有时间或触发条件
- `waiting`：等待外部人/事件
- `ready`：现在可以执行
- `done` / `cancelled` / `blocked`

每条承诺至少保存：来源、创建时间、截止时间、下次检查时间、下一步动作、通知策略、完成证据。cron 只负责唤醒，不再作为任务本身的唯一真相。

## P1：把主动性从“轮询聊天”改成“事件 + 简报”

保留设备、安全、到家离家这类事件触发；新增一个确定性 Briefing Builder，先汇总日程、提醒、天气、通勤、待回复、后台任务和家庭异常，再由模型压缩成一条自然消息。

主动打扰规则：

- 只有“需要决定、需要行动、即将错过、出现异常”才即时推送。
- 普通信息合并进早晚简报，不逐条轰炸。
- 相同事项去重，并记录“今天是否已提醒”。
- 支持安静时段、重要性和可延后程度。

## P2：接入真正的个人工作流

优先顺序：

1. 日历：课程、会议、出行前准备、冲突检测。
2. 沟通：识别需要回复的人与承诺，但发送前保留确认边界。
3. 项目与文件：会前自动找材料，会后记录下一步。
4. 生活：快递、账单、车辆、健康习惯只在有明确价值时提醒。

## P3：让记忆可解释、可过期

长期事实增加 `source`、`observed_at`、`confidence`、`expires_at`。用户最新说明和实时工具结果优先；过期行情、课程、位置和关系状态不能继续当事实使用。敏感信息只在相关场景检索，不进入无关提示词。

## 工程原则

- 线上只有一份运行架构真相；实验代码明确标记，不与 live 文档混写。
- 工具调用必须有结果验证，不能只凭退出码或模型自报成功。
- 所有主动消息都能追溯到具体事件或承诺。
- 新增能力优先注册到统一工具/任务层，不继续堆一次性脚本。
- 用真实用户任务做回归测试：家居控制、提醒、发文件、下载视频、后台任务完成通知、会话重启后的连续性。

## 推荐落地顺序

1. 统一承诺账本和迁移现有提醒。
2. 做早晚简报与打扰评分。
3. 接日历并做“会前准备 / 出发提醒”。
4. 给长期记忆补来源、时效与置信度。
5. 再扩展邮件、工作项目和更多生活服务。
